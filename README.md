 🍔 Food E-Commerce Website

 📌 About The Project

A full-stack food e-commerce web application built with React, Node.js, Express.js, and MongoDB.

The application allows users to browse food items, create an account, log in, manage their cart, place orders, and view their orders.

The frontend is built with React and Vite, while the backend provides REST APIs using Node.js and Express.js with MongoDB as the database.
 ✨ Frontend Features

- 🏠 Home page
- 🍔 Food menu and food cards
- 🛒 Shopping cart management
- 🔐 User registration and login
- 📦 My Orders
- 👨‍💼 Admin Dashboard
- 🍕 Admin product management
- 🔄 State management using Redux Toolkit
- 🧭 Page navigation using React Router
- 🔌 Backend API integration using Axios
- 🎨 Responsive and user-friendly interface
